Fast Installation

Deploy the Server Telemetry Agent in 60s

Zero heavy dependencies. The Aegis server agent runs seamlessly on any Linux distribution (Ubuntu, Debian, CentOS, Rocky, Alpine).

1

Download Server Agent

Clone the repository or copy the lightweight server_agent/ directory into /opt/aegis-agent.

sudo mkdir -p /opt/aegis-agent sudo git clone https://github.com/AustinFascal/aegis.git /tmp/aegis sudo cp -r /tmp/aegis/server_agent/* /opt/aegis-agent/
2

Configure Server Node

Copy the example configuration file and set your server identifier and optional FCM keys.

cd /opt/aegis-agent sudo cp config.example.json config.json sudo chmod 600 config.json sudo nano config.json
3

Enable Systemd Service

Install and start the persistent background systemd service for real-time telemetry surveillance.

sudo cp aegis-agent.service /etc/systemd/system/ sudo systemctl daemon-reload sudo systemctl enable --now aegis-agent sudo systemctl status aegis-agent
